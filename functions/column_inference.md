# Column Inference

열 이름이 없거나, 있더라도 의미를 파악하기 어려운 경우, 셀 값의 형식과 패턴을 보고 열의 성격을 추론한다.
classification_guide.md 및 각 Type_XXX.md에서 필요 시 참조한다.

---

## 추론 우선순위

1. 헤더 셀 값으로 판단 (열 이름이 명확한 경우)
2. 헤더가 없거나 불명확한 경우 → 데이터 값 패턴으로 추론
3. 패턴만으로 판단이 어려운 경우 → 인접 열과의 관계로 추론

---

## 패턴별 열 추론 기준

### 파일명 열

| 패턴 | 예시 | 판단 |
|------|------|------|
| `Play_VO_` 또는 `VO_` 로 시작하는 긴 문자열 | `Play_VO_Narrative_CINbc_CH01CS301_01_700000` | 엔진 이벤트명 또는 음성 파일명 |
| `VO_CN_`, `VO_KR_`, `VO_JP_` 로 시작 | `VO_CN_Narrative_CINbc_CH01CS301_01` | 언어 코드 포함 음성 파일명 |
| `Ex_vo_` 로 시작 | `Ex_vo_Story_TaFei_100004551_Korean` | 음성 파일명 |
| `알파벳+숫자` 조합의 짧은 ID | `CH01CS301`, `ark1050_001` | 씬 ID 또는 음성 ID (파일명이 아닌 그룹 ID일 가능성 있음) |
| `CBT2` 포함 | `CBT2音频资源名` | 구버전 파일명 — 숨김 처리 대상 |
| 행마다 값이 전부 다름 | — | 파일명 열 가능성 높음 |
| 여러 행이 동일한 값을 공유 | `CH01CS301`이 5행 연속 | 그룹 ID (씬/시퀀스 단위) — 파일명 아님 |

> **파일명 열이 여러 개인 경우:** 행마다 고유한 값을 가지는 열 중 가장 실제 납품 파일명에 가까운 것을 기준으로 선택. 나머지는 숨김 처리. 판단 기준은 해당 프로젝트의 납품 규격을 참고.

| 패턴 | 예시 | 판단 |
|------|------|------|

| `<player>`, `玩家`, `유저` | — | 플레이어 캐릭터 |
| `???` | — | 게임 내 숨김 처리된 캐릭터명 (실제 이름은 인접 열에 존재) |
| 동일 값이 여러 행 연속 (병합셀) | — | Type_짧은음성의 캐릭터명 열 가능성 |

### 대사 열

| 패턴 | 예시 | 판단 |
|------|------|------|
| 자연어 문장, 한국어 | `커튼을 걷어봤지만, 집 안에는 아무도 없었다.` | KR 대사 열 |
| 자연어 문장, 중국어 | `拉开了门帘，但屋内空无一人。` | CN 대사 열 (옵티컬 후보) |
| 자연어 문장, 영어 | `I gotta hack 'em first!` | EN 대사 열 (옵티컬 후보) |
| `eff(...)` 또는 `(...)` 형태의 지문 | `eff(伸懒腰的气声)`, `(기지개 켜는 호)` | 효과음/호흡 지문 — 대사 열에 포함 |

### 감정/어투 열

헤더 키워드(말투/감정/語気/配音备注/詳細/情绪 등)로 판단하되, **헤더가 달라도 셀 값 패턴이 아래에 해당하면 감정 열로 판단한다.**

| 패턴 | 예시 | 판단 |
|------|------|------|
| 짧은 감정/상황 설명, 한국어 | `조금 엄숙하게`, `뛰면서` | KR 감정 메모 |
| 짧은 감정/상황 설명, 중국어 | `边跑边说`, `不满`, `露米叹气`, `打滚耍赖的样子` | CN 감정 메모 |
| 짧은 감정/상황 설명, 일본어 | `落ち込んで`, `怒りながら` | JP 감정 메모 |
| 캐릭터 행동 묘사 구절 | `露米打滚耍赖的样子` | 감정 메모 (헤더가 "화면"/"画面"이어도 값이 이 형태면 감정 열) |
| 대사 열 바로 옆에 위치하고 짧은 값 | — | 감정/어투 열 가능성 높음 |

> **헤더가 "화면", "画面", "步骤" 등이어도** 실제 셀 값들이 캐릭터 감정/행동 묘사 문장이면 감정 열로 처리한다. 씬 설명("PART1 전투 진입", "화면 전환" 등 연출 설명)과 구별할 것.

> **[핵심] CN 감정 열과 KR 감정 열이 모두 있는 경우 반드시 구분:**
> - `col_emotion_cn` → 한자(중국어) 값 위주인 열 (예: `语气备注` 원본)
> - `col_emotion_kr` → 녹음 언어(KR=한국어, JP=일본어, EN=영어) 값이 있는 열 (예: `语气备注 KR`)
> - 헤더에 "KR" / "韩" / "한국어" 접미사가 있으면 무조건 `col_emotion_kr`
> - 중국어 열을 `col_emotion_kr`로 지정하는 것은 오류

### Duration 열

| 패턴 | 예시 | 판단 |
|------|------|------|
| `≤XX s`, `XXs`, `XX초` 형태 | `≤3s`, `2.5초` | 허용 녹음 시간 — Type_PV에서 주로 등장 |
| 순수 숫자 (소수점 포함) | `3.0`, `2.5` | 초 단위 duration |

## 열 추론 시 주의사항

- KR 컬럼이 여러 개인 경우, 인접 CN 열과의 관계를 보고 각각의 역할을 판단한다 (대사KR인지, 캐릭터명KR인지, 감정KR인지)
- 헤더 없이 데이터만 있는 열은 첫 몇 개 행의 값을 종합해서 판단한다
- 판단이 불명확한 열은 숨김 처리하고 Log에 기록한다
