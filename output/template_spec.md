# Template Spec — 합본 표준 조립 규칙

각 타입별 정리가 완료된 시트들을 하나의 합본 xlsx로 조립하는 규칙.
이 단계에서 AI의 판단은 최소화되며, 정해진 규칙대로 합치는 것이 주 작업이다.

---

## 합본 시트 순서

```
개괄 → 로그 → 대본 탭들 (그룹별 정렬)
```

---

## 대본 탭 그룹핑 순서

같은 그룹 내에서는 원본 파일 순서를 유지한다.

```
1. 메인
2. 전투
3. PV
4. 스킬
5. 캐릭터 대본
6. 짧은 음성
7. 음성
8. 스킨
```

---

## 시트명 규칙

- 기본: 원본 시트명 사용. **타입 라벨(`메인`, `짧은음성` 등)은 절대 붙이지 않는다.**
- `Sheet1`, `Sheet2` 등 의미 없는 시트명인 경우: 파일명 줄기에서 한글/영문/일본어 단어를 추출해 시트명으로 사용
- 원본 시트명이 순수 한자/숫자 등으로만 구성돼 정리 후 비어버리는 경우: 파일명 줄기에서 추출
- 동일한 시트명이 여러 파일에서 반복되는 경우 (명일방주 캐릭터 파일 등): `(캐릭터명)_(시트명)` 형식으로 변환
  - 예: `char_2027_왕.xlsx`의 `대사` 시트 → `왕_대사`
  - 예: `char_4056_티티.xlsx`의 `PV_티티` 시트 → `티티_PV` (시트명에 이미 캐릭터명 포함 시 중복 제거)
- 동일 시트명이 중복될 경우 `_2`, `_3` 접미사 자동 부여

---

## 대본 탭 열 구조

모든 대본 탭의 표준 열 순서:

| 열 | 설명 | 조건 |
|----|------|------|
| 파일명 | 납품 음성 파일명 | 항상 포함 |
| 캐릭터명 | 캐릭터명 | 항상 포함 |
| 감정 | 감정/어투 메모 | 항상 포함 |
| REC | 녹음 체크용 (비워두기) | 항상 포함 |
| 대사 | 녹음 언어 대사 | 항상 포함 |
| 옵티컬(원문) | 기준 옵티컬 언어 원문 (EN 또는 CN) | **optical=NONE이면 열 자체 제거** |
| ⏱ 검수 | 타이밍 검수 결과 자동 표기 | **optical=NONE이면 열 자체 제거** |
| ALT | 대체 대사 | 항상 포함 (데이터 없어도 숨김 처리 안 함) |
| [기타 원본 열] | **숨김 처리 (hidden=True)** — 절대 삭제하지 않음 | |

> **원본 열 보존 원칙:** 처리 과정에서 표준 열 구조에 포함되지 않는 원본 열은 반드시 숨김 처리(hidden=True)로 유지한다. 아예 빼거나 삭제하지 않는다. 나중에 기준 열이 잘못 선택된 경우 숨겨진 열로 교체할 수 있도록 보존한다.

> Type별로 추출되지 않는 열(파일명 없는 PV 등)은 해당 열을 비워두거나 생략한다.

## 개괄 시트

합본 맨 앞에 위치. **행 = 캐릭터, 열 = 대본 탭별 라인 수**로 구성된 집계 표.

### 구조

| 캐릭터명 | 성우명 | [대본탭1] | [대본탭2] | ... | **합계** |
|----------|--------|----------|----------|-----|--------|
| 루미 | (공란) | 42 | 8 | ... | 50 |
| 루루카 | (공란) | 18 | 3 | ... | 21 |

**열 구성 규칙:**
- 1열: 캐릭터명 (합본에 등장하는 모든 캐릭터, 대사 수 기준 내림차순 정렬)
- 2열: 성우명 (초기엔 공란, 캐스팅 후 수동 입력)
- 3열~: 각 대본 탭 이름 (그룹핑 순서대로 — 메인, 전투, PV, 음성, 스킨 순)
- 마지막 열: 합계 (해당 캐릭터의 전체 대사 수)

**행 구성 규칙:**
- 합본에 1줄이라도 대사가 있는 캐릭터는 전부 포함
- `내레이션` 등 특수 행도 포함
- 해당 탭에 대사가 없으면 빈칸 (0 아닌 빈칸)

**시각화:**
- 헤더 행: 배경 `#1F3864`, 흰 글씨
- 캐릭터명 열: bold
- 합계 열: bold, 배경 `#D9E1F2` (연파랑)
- 성우명 열: 배경 `#FFF2CC` (연노랑) — 입력 대기 표시

## 로그 시트

개괄 바로 다음에 위치. 분류 불가 또는 스킵된 시트 목록.

| 파일명 | 시트명 | 사유 |
|--------|--------|------|
| char_9999_테스트.xlsx | Sheet3 | 헤더 구조 불명확, 한국어 대사 확인 불가 |

스킵 사유 없이 전부 정상 처리된 경우 로그 시트는 생략한다.

---

## 시각화 규칙

| 대상 | 스타일 |
|------|--------|
| 헤더 행 | 배경 `#1F3864`, 흰 글씨, 맑은 고딕 10pt bold |
| 대사 열 | 배경 `#FFFDE7` (연노랑), 열 폭 50+, wrap_text |
| 캐릭터명 | bold |
| REC 열 | 배경 `#EA9999` (연빨강) |
| 감정 열 | 배경 `#FFE599` (연노랑) |
| 짝수 행 | 배경 `#F5F5F5` |
| 기타 원본 열 | `hidden=True` |
| 전체 | `wrap_text` 적용 |

## 피크 라인 표기

대사에 고강도 감정/음량이 예상되는 라인.

**감지 조건:**
- 느낌표 2개 이상 (`!!`)
- 녹음 언어별 감정어 포함:

```
KR: 비명 / 기합 / 으아 / 절규 / 소리치 / 폭발 / 외치 / 포효 / 분노 / 열받 / 살려 / 싫어 / 제발 / 도망 / 그만 / 아악 / 으윽
JP: 叫び / 絶叫 / 悲鳴 / 叫ぶ / 助けて / 怒り / 激怒 / 絶望 / 泣き / 叫んで
EN: scream / shriek / roar / yell / help me / rage / fury / cry out / no no no
```

**표기:** 대사 열 글씨만 `#FF0000` (빨강). 행 배경 변경 없음.

## 타이밍 검수 표기

duration 컬럼이 있는 타입(Type_PV 등)에서만 적용.

**초과 기준:** 예상 녹음 시간이 허용 시간의 110% 초과 시 플래그.

**예상 시간 계산:**
```python
def est_sec(text, lang='KR'):
    if lang == 'KR':
        return sum(1 for c in str(text) if '가' <= c <= '힣') / 6.5
    elif lang == 'JP':
        morae = sum(2 if '一' <= c <= '鿿' else 1
                    for c in str(text) if 'ぁ' <= c <= 'ん' or 'ァ' <= c <= 'ン' or '一' <= c <= '鿿')
        return morae / 5.5 if morae else len(str(text).split()) / 2.5
    elif lang == 'EN':
        return len(str(text).split()) / 2.5
```

**허용 시간 파싱:**
```python
def parse_duration(s):
    m = re.search(r'([\d.]+)\s*[sS초]', str(s).replace('≤','').replace('≦',''))
    return float(m.group(1)) if m else None
```

**표기:**

| 조건 | 스타일 |
|------|--------|
| 타이밍 초과 | 행 전체 배경 `#FFE5CC` (연주황) |
| 피크 + 타이밍 초과 동시 | 행 전체 주황 + 대사 글씨 빨강 |
