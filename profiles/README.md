# 프로젝트 프로파일 시스템

합본 자동화 도구는 프로젝트별 설정을 **프로파일**로 관리한다.
각 프로파일은 `hapbon-auto/profiles/<id>.json` 파일로 정의.

---

## 프로파일 목록

| ID | 이름 | 녹음 | 옵티컬 | 상태 |
|----|------|------|--------|------|
| `default` | Default (범용) | KR | EN | ✅ 사용 가능 |
| `reverse1999` | 리버스1999 (Reverse: 1999) | KR | EN | ✅ 사용 가능 |
| `muhandae` | 무한대 | KR | CN | 🚧 개발 예정 |

---

## 실행 방법

### 인터랙티브 모드 (권장)
```bash
python main.py --source <폴더> --output <경로.xlsx>
```
실행하면 아래 선택 메뉴가 표시됨:
```
=======================================================
  합본 자동화 — 프로젝트 선택
=======================================================
  1. Default (범용)
  2. 리버스1999 (Reverse: 1999)
  3. 무한대 (기획 중) ⚠ (개발 예정)
=======================================================
선택 (번호): 2

프로파일: 리버스1999 (Reverse: 1999)
프로젝트명 (Enter = '리버스1999'): 리버스1999
차수 (예: 3.7차, Enter = 생략): 3.7차
녹음 언어 KR/JP/EN (Enter = KR): 
옵티컬 언어 EN/CN/NONE (Enter = EN): 
```

### CLI 완전 지정 모드 (자동화용)
```bash
python main.py \
  --source <폴더> --output <경로.xlsx> \
  --profile reverse1999 \
  --project "리버스1999" --round "3.7차" \
  --optical EN --record KR
```

## 프로파일 설정 항목

```json
{
  "id": "...",                        // 고유 ID
  "display_name": "...",              // 표시명
  "description": "...",              // 설명
  "defaults": {
    "record": "KR",                   // 기본 녹음 언어
    "optical": "EN"                   // 기본 옵티컬 언어
  },
  "classify_extra": "...",           // Gemini 분류 프롬프트 추가 지침
  "functional_emotion_prefix": true,  // [功能] 감정 접두어 on/off
  "tab_naming": "standard"           // 탭명 생성 방식
}
```

### tab_naming 옵션

| 값 | 설명 | 예시 |
|----|------|------|
| `standard` | 파일명/시트명 기반 | `이글_SP_이글_음성_` |
| `reverse1999` | 리버스1999 형식 | `이글 (음성)`, `노티카 (스킨)` |
| `original` | 원본 시트명 그대로 유지 | `무한대 스크립트 ACT2` |

## 리버스1999 전용 특이사항

### 캐릭터음성 파일 헤더 패턴
```
ID | 功能 | _ | 语气备注(col_emotion_cn) | KR(col_emotion_rec) | 功能备注 | 终选语音(col_dialogue_cn) | _ | KR(col_dialogue_rec) | Alt | 语音命名(col_filename)
```
- `语气备注` 다음 KR 열 → `col_emotion_rec` (KR 감정)
- `终选语音` 다음 KR 열 → `col_dialogue_rec` (KR 대사)

### 메인 대본 (타인의 슬픔 형태)
- `语音命名`이 열 19 내외 (멀리 있음)
- KR 열이 4개 이상: 캐릭터명KR(6), 직책KR(8), 대사KR(10), 감정KR(17)

### 감정 표시
- `functional_emotion_prefix: false` → `[功能]` 접두어 없음
- 순수 KR 감정만 표시: `미소 지으며 인사, 마지막엔 약간 부끄러워하며`

### 탭 순서 및 이름 (3.7차 예시)
| 원본 파일명 | 탭명 |
|------------|------|
| 타인의 슬픔 3.7... | 타인의 슬픔 |
| 올로그 3.7... | 올로그 |
| 보스 및 전투 대화 3.7... | 전투 |
| 리아논 PV 3.7... | 리아논 (PV) |
| 버전 PV 3.7... | 버전 (PV) |
| 리아논 캐릭터 심층 분석 3.7... | 리아논 (캐릭터 분석) |
| SP 이글 음성 3.7... | 이글 (음성) |
| 노티카 스킨 3.7... | 노티카 (스킨) |
| 리아논 음성 3.7... | 리아논 (음성) |
| 미스 스트레인저 음성 3.7... | 미스 스트레인저 (음성) |
| 코펠리아 음성 3.7... | 코펠리아 (음성) |
| 코펠리아 스킨 3.7... | 코펠리아 (스킨) |
| 파투투 스킨 3.7... | 파투투 (스킨) |

## 새 프로파일 추가 방법

1. `hapbon-auto/profiles/<id>.json` 생성
2. `profile.py`의 `_PROFILE_ORDER` 리스트에 추가
3. 필요 시 `profile.py`에 전용 `make_sheet_name_<id>()` 함수 추가
4. `_resolve_sheet_name()` (main.py)에 라우팅 추가
