# Type_PV — 처리 매뉴얼

영상에 통으로 믹싱되는 PV/스킬PV 대본. 개별 음성 파일이 아닌 영상 납품용이므로 파일명 열이 없다.

---

## 1. 헤더 행 찾기

- 1행이 헤더가 아닐 수 있음. 빈 행 이후 `角色`, `화자`, `KR`, `语气`, `时长` 등 대본 관련 컬럼명이 처음 등장하는 행이 헤더
- 아크나이츠 PV의 경우 1~2행이 빈 행이고 3행이 헤더인 케이스 있음

---

## 2. 열 인식 및 매핑

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | **없음** — PV는 영상 통합 믹싱이므로 파일명 열 없음. 파일명 열 비워둠 |
| **캐릭터명** | `角色`(CN) + 옆 `KR` 열 쌍. 또는 `화자` 열(한국어로만 표기된 경우). column_inference.md 캐릭터명 패턴 참조 |
| **감정** | `语气`(CN) + 옆 `KR` 열 쌍. 또는 감정/어투 설명이 들어있는 열 |
| **대사** | KR 대사가 들어있는 열. `中(...)`(CN) 옆 KR 열, 또는 가장 긴 한국어 문장이 있는 열 |
| **ALT** | 없는 경우가 대부분. 있으면 포함 |
| **옵티컬** | CN 원문 열 (`中(校对定稿...)` 등) 또는 EN 열. 입력 파라미터 기준 언어 선택 |
| **duration** | `时长（≤XX s)`, `预期秒数` 등. 있는 경우 ⏱ 검수 대상 |

### 감정 열이 CN/KR 쌍인 경우
`语气`(CN 감정) + 옆 KR 감정 열이 둘 다 있으면 KR 감정을 사용한다.

---

## 3. 스킵할 행

- 캐릭터명과 대사가 모두 비어있는 빈 행
- 챕터/씬 구분 제목 행 (대사 없이 장면 설명만 있는 행)

---

## 4. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | **비워둠** |
| 캐릭터명 | KR 캐릭터명 |
| 감정 | KR 감정/어투 메모 (없으면 빈칸) |
| REC | 비워두기 |
| 대사 | KR 대사 |
| ALT | 없으면 빈칸 |
| 옵티컬(원문) | CN 또는 EN 원문 |
| ⏱ 검수 | duration 있으면 타이밍 검수 적용, 없으면 빈칸 |
| [기타 원본 열] | 숨김 처리 |

---

## 5. 특수 처리 규칙

### duration 있는 경우 (리버스1999 캐릭터PV 등)
`时长（≤XX s)` 열 값을 파싱해서 ⏱ 검수 적용.
template_spec.md 타이밍 검수 규칙 참조.

### 스킬PV — 캐릭터명 CN/KR 쌍이 같은 행에 혼재
열2(`语气`)가 CN 감정, 열3이 KR 감정, 열5(`角色`)가 CN 캐릭터명, 열6이 KR 캐릭터명인 구조.
헤더에 `KR` 표기 없이 CN 열 바로 옆에 위치하는 경우가 있음 → column_inference.md 패턴으로 판단.

### 아크나이츠 PV — 헤더가 3행, 옵티컬이 JP
헤더 위치 3행. `重要旁白` 열이 CN 원문, `TRANSLATION` 열이 JP, `대사` 열이 KR.
기준 옵티컬 언어가 CN이면 `重要旁白` 열 사용. JP는 옵티컬 대상 아님.

### 旁白(내레이션) 행
캐릭터명 없이 대사만 있는 행 → 캐릭터명 열에 `내레이션` 기입 후 포함.

---

## 6. 예외 케이스

- duration 열 없는 경우 → ⏱ 검수 열 비워둠
- ALT 열 없는 경우 → ALT 열 생략
- 캐릭터명이 한국어로만 표기된 경우 → 그대로 사용
- 감정 열이 CN만 있고 KR 없는 경우 → CN 감정 그대로 사용
