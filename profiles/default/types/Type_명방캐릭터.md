# Type_명방캐릭터 — 처리 매뉴얼

아크나이츠(명일방주) 캐릭터 파일의 설정 시트. 대본이 아닌 캐릭터 프로필 정보 시트.
더빙 디렉션의 참고 자료로 합본에 포함하되, 원본 형태 그대로 첨부한다.

---

## 1. 식별 기준

- 시트명이 `설정`인 경우
- 헤더 없음 (또는 빈 헤더)
- 키-값 형태로 구성 (B열: 항목명, C열: 값)
- 대사 없음, 파일명 없음
- 캐릭터 번호(`No.XXXX`), 영문명, 레어도, 소속/출신/종족, 말투/성격, 소개 등으로 구성

---

## 2. 처리 방법

**원본 형태 그대로 합본에 포함한다. 별도 가공 없음.**

- 열 매핑, 데이터 추출, 표준 열 구조 변환 없음
- 시각화 규칙 (헤더 색상, 대사 열 노랑 등) 적용 안 함
- 원본 셀 값, 셀 너비, 스타일 최대한 유지

---

## 3. 시트명 변환

명일방주 합본의 경우 여러 캐릭터 파일이 합산되므로 시트명 충돌 방지:
- `char_1050_첸SP.xlsx`의 `설정` → `첸SP_설정`
- `char_2027_왕.xlsx`의 `설정` → `왕_설정`
- template_spec.md 시트명 규칙 참조

---

## 4. 합본 내 위치

해당 캐릭터의 다른 시트들(캐릭터음성, PV 등) 바로 앞에 배치한다.

예:
```
왕_설정 → 왕_대사 → 왕_PV → 티티_설정 → 티티_대사 → ...
```

---

## 5. 개괄 시트에서의 처리

Type_명방캐릭터 시트는 대사 수 집계 대상이 아니다.
개괄 시트의 캐릭터별 대사 수 집계에서 제외.

---

## 6. 예외 케이스

- 설정 시트가 없는 파일 → 해당 캐릭터 설정 시트 생략
- 설정 시트 내용이 비어있는 경우 → 빈 시트로 포함하거나 생략 (담당자 판단)
