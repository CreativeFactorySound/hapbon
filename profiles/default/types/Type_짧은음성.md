# Type_짧은음성 — 처리 매뉴얼

캐릭터명이 병합셀로 묶여 여러 행을 아우르는 구조의 대본. 스킨/재録/짧은 음성 대본 등.
대사 길이는 짧을 수도 있고 길 수도 있음 (1어절~긴 문장 모두 가능).

---

## 1. 헤더 행 찾기

대부분 1행이 헤더. `编号`, `角色`, `台词`, `语音备注`, `语音命名`, `キャラ`, `台詞`, `說明や注意事項` 등 컬럼명 확인.

---

## 2. 병합셀 전면 확장 처리 (핵심)

이 타입의 가장 중요한 처리 규칙.

**원본 구조:**
```
행2: [캐릭터CN | 캐릭터KR | 감정CN | 감정KR | 대사CN | 대사KR | 파일명]
행3: [병합셀   | 병합셀   | 병합셀 | 병합셀 | 대사CN | 대사KR | 파일명]
행4: [병합셀   | 병합셀   | 병합셀 | 병합셀 | 대사CN | 대사KR | 파일명]
...
행N: [새캐릭터CN | 새캐릭터KR | ...]
```

**처리 방법:**
1. openpyxl로 파일 읽을 때 병합셀 정보 확인 (`ws.merged_cells`)
2. **모든 열**의 병합셀 범위를 통합 맵으로 구성 — 캐릭터명뿐 아니라 감정(詳細), 파일명 등 병합된 열 전체 포함
3. 각 행/열 좌표에서 값 조회 시 병합셀 맵에서 먼저 확인, 없으면 실제 셀 값 사용

**주의:** `read_only=True`로 열면 병합셀 정보가 손실됨. 반드시 일반 모드로 열어야 함.

```python
# 병합셀 전면 확장 예시
wb = load_workbook(filepath, data_only=True)  # read_only=False
ws = wb[sheet_name]

# 모든 열의 병합 범위를 (row_0, col_0) → 값 맵으로 구성
merged_map = {}
for mr in ws.merged_cells.ranges:
    val = ws.cell(mr.min_row, mr.min_col).value
    s = str(val).strip() if val is not None else ""
    c0 = mr.min_col - 1
    for r1 in range(mr.min_row, mr.max_row + 1):
        merged_map[(r1 - 1, c0)] = s

def _mv(row_vals, row_0, col_0):
    if col_0 < 0: return None
    mv = merged_map.get((row_0, col_0))
    if mv is not None: return mv or None
    return row_vals[col_0] if col_0 < len(row_vals) else None
```

## 3. 열 인식 및 매핑

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | `语音命名`, `説明や注意事項` 등. 행마다 고유한 값 |
| **캐릭터명** | `角色`/`キャラ`/`配音对象` KR 열. 병합셀 풀어서 각 행에 채움 |
| **감정** | `语音备注`/`詳細` 등 짧은 감정·지문 설명 열. 병합셀 풀어서 채움 |
| **대사** | `台词`/`台詞` 등 녹음 받는 언어의 주 대사 열 |
| **ALT** | `Alt`/`alt`/`ALT`/예비 열 |
| **옵티컬** | 입력 파라미터 기준 언어 열 (EN이면 영어 열, CN이면 중국어 대사 열). 녹음 대상 언어와 다른 열 |

## 6. 특수 처리 규칙

### 其他备注 열
`其他备注`(기타 비고) 열에 `拆分标记`, `选自正文原句`, `通用短语音` 등 표기가 있는 경우.
→ 숨김 처리하지 않고 감정 열 뒤 참고 열로 포함 권장.

### 녹음 언어 번역이 없는 행
번역 누락 가능성. 대사 열 비워두고 감정 열에 `[번역 없음]` 표기 후 포함.

### 이미지 보존 (캐릭터 일러스트)
소스 xlsx에 twoCellAnchor 방식으로 삽입된 캐릭터 이미지가 있는 경우:
- zipfile로 직접 이미지 추출 (openpyxl의 `ws.images`로는 이 방식 이미지를 읽을 수 없음)
- 이미지가 위치한 셀의 행/열 → 캐릭터명 병합셀 맵과 대조하여 해당 캐릭터에 매핑
- 합본 시트에서 해당 캐릭터 섹션의 첫 행 오른쪽 끝 열에 배치 (최대 270×450px)

## 7. 예외 케이스

- 감정 CN만 있고 KR 없는 경우 → CN 감정 그대로 사용
- 파일명 없는 행 → 파일명 빈칸
- 병합셀이 아닌 일반 셀로 캐릭터명이 반복 입력된 경우 → 그대로 사용
- 이미지 없는 파일 → 이미지 열 생략
