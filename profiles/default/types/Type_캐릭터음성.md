# Type_캐릭터음성 — 처리 매뉴얼

특정 캐릭터 전용 음성 대본. 파일 또는 시트 자체가 한 캐릭터에 종속되어 캐릭터명 컬럼이 없다.
리버스1999 角色语音, 스킨음성, 아크나이츠 캐릭터 대사 시트가 이 타입에 해당.

---

## 1. 헤더 행 찾기

대부분 1행이 헤더. `ID`, `功能`, `终选语音`, `KR`, `语音命名` 등 컬럼명이 1행에 있음.
아크나이츠의 경우 `台詞番号`, `ボイス名` 등 일본어 컬럼명으로 된 경우도 있음.

---

## 2. 캐릭터명 추출

캐릭터명 컬럼이 없으므로 **파일명 또는 시트명에서 캐릭터명을 추출**한다.

| 케이스 | 추출 방법 |
|--------|----------|
| `로렌츠_버터플라이_3_5洛伦兹蝴蝶角色语音_251230.xlsx` | 파일명에서 한국어 캐릭터명 추출 → `로렌츠 버터플라이` |
| `3_5_스킨_음성.xlsx`의 `코르부스` 시트 | 시트명에서 추출 → `코르부스` |
| `char_1050_첸SP.xlsx`의 `대사` 시트 | 파일명에서 추출 → `첸(SP)` |

파일명/시트명에서 캐릭터명 추출 시:
- 버전 정보(`3_5`, `251230` 등), 언어 표기(`洛伦兹蝴蝶角色语音` 등) 제거
- 한국어 캐릭터명이 파일명에 포함된 경우 우선 사용
- 없으면 CN 캐릭터명 사용

추출한 캐릭터명을 모든 행의 캐릭터명 열에 채워넣는다.

---

## 3. 열 인식 및 매핑

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | `语音命名`, `台詞番号`(아크나이츠), `ark_xxx` 패턴 값. 행마다 고유한 값 |
| **캐릭터명** | 파일명/시트명에서 추출 (위 참조) |
| **감정** | `语气备注`(CN) + 옆 KR 열 쌍. 또는 감정 설명이 있는 열. 아크나이츠는 대사 열 다음 열 |
| **대사** | `终选语音`(CN) + 옆 KR 열. 또는 가장 긴 한국어 문장 열. 아크나이츠는 CN 대사 옆 KR 열 |
| **ALT** | `Alt`, `alt` 열 (있는 경우만) |
| **옵티컬** | CN 원문 대사 열 또는 EN 열. 입력 파라미터 기준 |
| **功能** | `功能`, `ボイス名` 등 — 게임 내 음성 사용 상황. 숨김 처리하지 않고 감정 열 앞에 참고용으로 포함 권장 |

### 리버스1999 vs 아크나이츠 구조 차이

**리버스1999** (角色语音, 스킨음성):
- `ID` / `功能` / `功能备注` / CN대사 / EN대사 / KR대사 / CN감정 / KR감정 / `语音命名` / EN(중복)
- 감정이 CN/KR 쌍으로 분리되어 있음

**아크나이츠**:
- `台詞番号`(파일명) / `ボイス名`(功能 역할) / CN대사 / KR대사 / KR감정
- 감정 열이 KR만 있음, 별도 CN 감정 없음
- 헤더가 일본어로 표기됨 → column_inference.md 패턴으로 판단

### 스킨음성 — 시트마다 ALT 열 유무 다름
`코르부스` 시트: ALT 열 없음
`키페리나` 시트: ALT 열 있음 (열5)
→ 시트별로 ALT 열 존재 여부 개별 확인

## 4. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | `语音命名` 또는 파일명 ID 값 |
| 캐릭터명 | 파일명/시트명에서 추출한 캐릭터명 (전 행 동일) |
| 감정 | KR 감정/어투 메모 |
| REC | 비워두기 |
| 대사 | KR 대사 |
| ALT | alt 열 값 (없으면 빈칸) |
| 옵티컬(원문) | CN 또는 EN 원문 |
| ⏱ 검수 | 비워두기 (duration 없는 타입) |
| [기타 원본 열] | 숨김 처리 |

---

## 5. 특수 처리 규칙

### 功能/ボイス名 열 처리
게임 내 어느 상황에 재생되는 음성인지 설명하는 열.
숨김 처리하지 않고 감정 열 바로 앞에 참고 열로 포함한다.
(녹음 디렉션에 유용한 맥락 정보)

### 명일방주 합본 시 시트명 변환
여러 캐릭터 파일이 합산되는 경우 시트명 충돌 방지:
- `char_2027_왕.xlsx`의 `대사` → `왕_대사`
- `char_4056_티티.xlsx`의 `대사` → `티티_대사`
- template_spec.md 시트명 규칙 참조

---

## 6. 예외 케이스

- ALT 열 없는 경우 → ALT 열 생략
- 감정 열이 CN만 있는 경우 → CN 감정 그대로 사용
- 파일명 열이 없는 경우 (ID만 있는 경우) → ID를 파일명으로 사용
- EN 열이 두 개 있는 경우 (리버스1999 일부) → 앞의 EN 열을 옵티컬로, 뒤의 중복 EN 열은 숨김
