## 핵심 특이사항

### 감정 표시
- `functional_emotion_prefix: false` → `[功能]` 접두어 없음
- 순수 KR 감정만 표시: `미소 지으며 인사, 마지막엔 약간 부끄러워하며`

### 타인의 슬픔 (메인 대본) KR 열 구조
```
大纲简述 | 调整日期 | ... | 步骤 | 配音对象 | KR(캐릭터명) | 对象 | KR(직책) | 对话文本 | KR(대사) | ... | 配音备注 | KR(감정) | BGM | 语音命名
```
- KR이 4개 이상 등장 — 각각의 역할이 다름
- 步骤 열: `画面`/`特效` → skip, `旁白`/`头像对话`/`spine对话` → 포함

### 캐릭터음성 헤더 구조
```
ID | 功能 | [空/功能备注] | 语气备注 | KR(감정) | 功能备注 | 终选语音 | [空 여럿] | KR(대사) | alt | [이유] | 语音命名
```
- `语气备注` → col_emotion_cn (절대 col_emotion_rec 아님)
- `语气备注` 바로 다음 KR → col_emotion_rec
