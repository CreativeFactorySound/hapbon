# 시트 분류 가이드 — 리버스:1999 전용

> base: `profiles/default/functions/classification_guide.md`

---

## 타입 판별 흐름

```
파일명/시트명 + 헤더 미리보기 확인
        ↓
1. 헤더에 ID + 功能 + 终选语音 조합 → Type_캐릭터음성
2. 流程节点 열 존재 → Type_전투
3. 파일명에 'PV' / '캐릭터 심층 분석' 포함 → Type_PV (확인)
4. KR 열이 4개 이상 + 语音命名 존재 → Type_메인
5. 위 해당 없음 → 면밀히 확인 후 SKIP
```

---

## Type_캐릭터음성 판별

**확정 조건:** 헤더 행에 `ID`, `功能`, `终选语音` 가 모두 존재

**해당 파일 패턴:**
- `[캐릭터명] 음성 X.X차...` (기본 캐릭터 음성)
- `SP [캐릭터명] 음성 X.X차...` (SP 버전 캐릭터 음성)
- `[캐릭터명] 스킨 X.X차...` (스킨 음성)

**char_name_kr 추출:**
파일명 한국어 prefix에서 추출. SP 제거 후 캐릭터명만.
- `SP 이글 음성 3.7차...` → `이글`
- `노티카 스킨 3.7차...` → `노티카`
- `리아논 음성 3.7차...` → `리아논`

---

## Type_메인 판별

**확정 조건:** 헤더에 `配音对象`, `对话文本`, `语音命名` 가 있고 `KR` 열이 4개 이상

**해당 파일 패턴:**
- `타인의 슬픔 X.X차...` — 메인 스토리 대본
- `올로그 X.X차...` — 메인 스토리 부속

**주의:** `올로그` 파일은 대사 행이 적고 씬 설명 행이 많음. `步骤` 열 skip 처리 중요.

---

## Type_전투 판별

**확정 조건:** 헤더에 `流程节点` 열 존재

**해당 파일 패턴:**
- `보스 및 전투 대화 X.X차...`

**battle_role 구분:**
- `boss` 시트 (시트명/내용에 보스 관련 키워드): `battle_role: "boss"`
- 일반 전투: `battle_role: "normal"`
- 보스 시트를 앞에 배치 (processor가 자동 처리)

---

## Type_PV 판별

**확정 조건:** 파일명에 `PV` 포함 OR `캐릭터 심층 분석` 포함 + 헤더에 파일명 열 없음

**해당 파일 패턴:**

| 파일명 패턴 | char_name_kr | 탭명 |
|------------|-------------|------|
| `[캐릭터명] PV X.X차...` | 캐릭터명 | `[캐릭터명] (PV)` |
| `버전 PV X.X차...` | null | `버전 (PV)` |
| `[캐릭터명] 캐릭터 심층 분석 X.X차...` | 캐릭터명 | `[캐릭터명] (캐릭터 분석)` |

**주의:** PV 파일은 파일명(語音命名) 열이 없고, 대신 `时长`(허용 시간) 열이 있을 수 있음.

---

## SKIP 대상

- 녹음 언어(KR) 대사가 없는 시트
- `美术需求`, `音效需求`, `ID索引用` 등 비대본 시트
- 모든 행에 `无需录制` 또는 `더빙 불필요` 표기된 시트
- 숨겨진 시트 (veryHidden / hidden — main.py가 자동 처리)
