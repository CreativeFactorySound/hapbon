## 탭명 생성 규칙 (`tab_naming: "reverse1999"`)

파일명 한국어 prefix에서 `캐릭터명 (유형)` 형태로 추출.

### 변환 규칙

| 파일명 패턴 | 탭명 |
|------------|------|
| `타인의 슬픔 X.X차...` | `타인의 슬픔` |
| `올로그 X.X차...` | `올로그` |
| `보스 및 전투 대화 X.X차...` | `전투` (고정) |
| `[캐릭터명] PV X.X차...` | `[캐릭터명] (PV)` |
| `버전 PV X.X차...` | `버전 (PV)` |
| `[캐릭터명] 캐릭터 심층 분석 X.X차...` | `[캐릭터명] (캐릭터 분석)` |
| `[캐릭터명] 음성 X.X차...` | `[캐릭터명] (음성)` |
| `SP [캐릭터명] 음성 X.X차...` | `[캐릭터명] (음성)` (SP 제거) |
| `[캐릭터명] 스킨 X.X차...` | `[캐릭터명] (스킨)` |

### TYPE 키워드 정규화 순서 (순차 적용)

```python
TYPE_KEYWORDS = [
    (r"\b캐릭터\s*심층\s*분석\b", "(캐릭터 분석)"),
    (r"\b캐릭터\s*PV\b",           "(캐릭터 PV)"),
    (r"\b스킬\s*PV\b",             "(스킬 PV)"),
    (r"^SP\s+",                    ""),           # SP 접두어 제거 (문두)
    (r"\b음성\b",                  "(음성)"),
    (r"\b스킨\b",                  "(스킨)"),
    (r"(?<!\()\bPV\b(?!\))",       "(PV)"),       # 이미 괄호 안이면 스킵
]
```

## 시각화

base 규칙 동일 적용:
- 캐릭터명 열: `#9DC3E6` (연파랑), bold
- 감정 열: `#FFE599` (연노랑)
- 대사 열: `#FFFDE7` (연노랑), 26pt bold
- 헤더: `#1F3864` (진남색), 흰 글씨
- 타이밍 초과: 행 전체 `#FFE5CC` (연주황)
- 피크 라인: 대사 글씨 `#FF0000` (빨강)
