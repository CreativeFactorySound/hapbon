## 대상 파일

| 파일명 패턴 | char_name_kr | 탭명 |
|------------|-------------|------|
| `[캐릭터명] PV X.X차...` | 캐릭터명 | `[캐릭터명] (PV)` |
| `버전 PV X.X차...` | null | `버전 (PV)` |
| `[캐릭터명] 캐릭터 심층 분석 X.X차...` | 캐릭터명 | `[캐릭터명] (캐릭터 분석)` |

---

## 특이사항

- 파일명(語音命名) 열 없음 → `파일명` 열이 빈칸
- `时长` (허용 시간) 열이 있을 수 있음 → `col_duration` 탐지 시 타이밍 검수 자동 실행
- 화자(캐릭터명)와 대사 구조로만 구성
- 단일 캐릭터 PV: `char_name_kr` 설정 → 탭명에 캐릭터명 포함
- 버전 PV: 여러 캐릭터 등장 → `char_name_kr: null`

---

## 감정

- 리버스1999 PV는 별도 감정 열이 없는 경우가 많음
- `col_emotion_rec = -1` 이면 감정 열 빈칸으로 출력
