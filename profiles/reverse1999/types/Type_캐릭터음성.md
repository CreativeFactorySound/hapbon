## 대상 파일

| 파일명 패턴 | 설명 |
|------------|------|
| `[캐릭터명] 음성 X.X차...` | 기본 캐릭터 음성 |
| `SP [캐릭터명] 음성 X.X차...` | SP 버전 캐릭터 음성 |
| `[캐릭터명] 스킨 X.X차...` | 스킨 음성 |

---

## 헤더 구조

```
[0]ID | [1]功能 | [2]空/功能备注 | [3]语气备注 | [4]KR | [5]功能备注 | [6]终选语音 | [7~N]空 | [N+1]KR | [N+2]alt | [N+3]이유 | [N+4]语音命名
```

헤더 행: row0 (첫 번째 행)

---

## 컬럼 매핑

```python
cls = {
    "header_row": 0,
    "col_functional": 1,      # 功能
    "col_emotion_cn": 3,      # 语气备注 ← 중국어 감정
    "col_emotion_rec": 4,     # KR (语气备注 바로 다음) ← 한국어 감정
    "col_dialogue_cn": 6,     # 终选语音 ← 중국어 최종 대사
    "col_dialogue_rec": N+1,  # KR (终选语音 이후 첫 KR, 빈 열 건너뜀)
    "col_alt": N+2,           # alt
    "col_filename": N+4,      # 语音命名
    "char_name_kr": "이글",   # 파일명에서 추출한 한국어 캐릭터명
}
```

### ⚠ 핵심 구별 규칙
- `语气备注` (col 3) → **col_emotion_cn** (중국어, 한자 포함)
- `语气备注 바로 다음 KR` (col 4) → **col_emotion_rec** (한국어)
- 위 둘을 절대 혼동하지 말 것. `col_emotion_rec` 셀에 한자가 포함되면 오류.

## 감정 표시

리버스1999는 `functional_emotion_prefix: false` 이므로:

```python
# functional이 있어도 감정 앞에 붙이지 않음
emotion = emotion_rec or emotion_cn or ""
# 결과: "미소 지으며 인사, 마지막엔 약간 부끄러워하며 웃는"
# (X) "[선택] 미소 지으며 인사..."  ← 이렇게 하면 안 됨
```

## char_name_kr 추출 규칙

파일명에서 한국어 prefix → 캐릭터명만 추출:

| 파일명 | char_name_kr |
|--------|-------------|
| `이글 음성 3.7차...` | `이글` |
| `SP 이글 음성 3.7차...` | `이글` (SP 제거) |
| `노티카 스킨 3.7차...` | `노티카` |
| `리아논 음성 3.7차...` | `리아논` |
| `미스 스트레인저 음성 3.7차...` | `미스 스트레인저` |
| `코펠리아 음성 3.7차...` | `코펠리아` |
| `파투투 스킨 3.7차...` | `파투투` |

## 행 처리 규칙

### 스킵 행
- 파일명 없고 대사도 없는 빈 행
- 헤더 반복 행 (语音命名 등 헤더 키워드 재등장)
- `无需录制` 표기 행

### 데이터 행
- 파일명(语音命名) 기준 1행 1음성
- alt 열: 예비 대사 (녹음 시 참고용)
- 대사가 중국어만 있고 KR이 없으면 → `[번역 없음]` 표기
