# Type_메인 — 처리 매뉴얼

스토리 대본. 여러 캐릭터가 등장하며 장면 단위로 대사가 이어지는 구조.
합본의 '메인 대본' 탭을 구성하는 타입.

---

## 1. 헤더 행 찾기

1행이 헤더가 아닐 수 있다. 다음 기준으로 헤더 행을 판단한다:

- `配音对象`, `角色`, `캐릭터`, `KR`, `语音命名`, `对话文本` 등 대본 관련 컬럼명이 처음 등장하는 행
- 그 위의 행들은 프로젝트 개요/PART 설명 등 메타 정보 → 스킵

---

## 2. 열 인식 및 매핑

아래 표준 추출 열을 찾아야 한다. 열 이름이 다를 수 있으므로 column_inference.md를 참조해서 패턴으로 판단한다.

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | `语音命名`, `音频资源名`, `Ex_vo_`로 시작하는 값이 있는 열. 행마다 고유한 값. 파일명 열이 여러 개면 기준 열 하나 선택 후 나머지 숨김 |
| **캐릭터명** | `配音对象`(CN) 옆 KR 열. KR 캐릭터명이 들어있는 열 |
| **감정** | `配音备注`, `감정` 등. 짧은 감정/상황 설명이 들어있는 열 |
| **대사** | KR 대사가 들어있는 열. `对话文本` 옆 KR 열, 또는 가장 긴 한국어 문장이 있는 열 |
| **ALT** | `alt`, `Alt`, `ALT` 열 |
| **옵티컬** | CN 원문 대사 열 (`对话文本（主角）` 등) 또는 EN 참고 열 (`英文参考`). 프로젝트 입력 파라미터의 기준 옵티컬 언어에 따라 선택 |

### KR 컬럼이 여러 개인 경우

이 타입은 KR 컬럼이 2~4개 혼재하는 경우가 많다. 인접한 CN 열과의 관계를 보고 역할을 판단한다:

- `配音对象` 옆 KR → 캐릭터명KR (더빙 대상 캐릭터)
- `对象` 옆 KR → 게임 내 표시 캐릭터명KR (직책/별명 등) → 숨김 처리
- `对话文本` 옆 KR → **대사KR** ← 핵심
- `配音备注` 옆 KR → 감정KR

---

## 3. 스킵할 행

대사 행이 아닌 행들이 중간에 끼어 있다. 다음 패턴이면 스킵:

- **PART 제목행**: 1열에 `PART X`, `第X章` 등 챕터 설명 텍스트가 있고 대사가 없는 행
- **画面/씬 설명행**: 연출 유형 열이 `画面`, `氛围图` 등이고 캐릭터명이 없는 행
- **빈 행**: 모든 주요 열이 비어있는 행

### 旁白(내레이션) 행 처리

연출 유형 열이 `旁白`인 행은 대사 행이지만 캐릭터명이 없다.
→ 캐릭터명 열에 `내레이션`으로 채워서 포함.
→ 파일명도 없는 경우 파일명 빈칸 처리.

## 4. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | `语音命名` 또는 기준 파일명 열 값 |
| 캐릭터명 | KR 캐릭터명 |
| 감정 | 감정/어투 메모 (없으면 빈칸) |
| REC | 비워두기 |
| 대사 | KR 대사 |
| ALT | alt 열 값 (없으면 빈칸) |
| 옵티컬(원문) | CN 또는 EN 원문 (입력 파라미터 기준) |
| ⏱ 검수 | 비워두기 (duration 없는 타입) |
| [기타 원본 열] | 숨김 처리 |

---

## 5. 특수 처리 규칙

### 파일명 열이 여러 개인 경우
행마다 고유한 값인지 확인 후 납품 규격에 가장 가까운 열을 기준으로 선택.
`CBT2` 포함 열, 구버전 열은 무조건 숨김 처리.

### 대사가 CN에만 있고 KR이 없는 행
번역 누락 가능성. 대사 열 비워두고 포함. 감정 열에 `[번역 없음]` 표기.

### 시트가 2개 이상인 경우 (`正文终稿`, `正文终稿 (2)` 등)
각 시트를 별도로 처리. KR 열이 없는 시트는 스킵.

## 6. 합본 시각화

template_spec.md 기본 규칙을 따르되, 이 타입에서 추가로 적용:

| 열 | 배경색 |
|----|--------|
| REC | `#EA9999` (연빨강) — 체크 용도 |
| 캐릭터명 | `#92D050` (연초록) |
| 감정 | `#FFE599` (연노랑) |
| 대사 | `#FFFDE7` (연노랑, template_spec 기본) |

旁白 행의 캐릭터명(`내레이션`) → 이탤릭체 적용.

---

## 7. 예외 케이스

- ALT 열 없는 경우 → ALT 열 생략
- 감정 열 없는 경우 → 감정 열 빈칸
- EN 옵티컬 없고 CN만 있는 경우 → CN을 옵티컬로 사용
- 헤더 없이 데이터 시작하는 경우 → column_inference.md 패턴으로 열 추론
