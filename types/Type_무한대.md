# Type_무한대 — 처리 매뉴얼

ADR/Wild 구분이 핵심인 대본. 타임코드 기반 ADR 작업과 자유 녹음(Wild) 라인이 혼재한다.
레벨인피니티(무한대) 프로젝트의 대본 형식.

> **주의:** 이 타입은 실제 합본 샘플 검토 후 추가 보완 예정. 현재는 파일 분석 기반 초안.

---

## 1. 헤더 행 찾기

1행이 헤더. `序号`, `源文件`, `说话人`, `时间戳`, `台词`, `KR Text`, `是否收录` 등 확인.
헤더 컬럼명이 CN/EN 이중 표기인 경우 많음 (`说话人\nCharacter Names` 등).

---

## 2. 시트 구조

시트 하나 = 에피소드/퀘스트 하나.
파일 내 시트가 24개 등 다수인 경우, 각 시트를 개별 탭으로 처리하거나 하나로 합산할지 담당자 확인 필요.

---

## 3. 열 인식 및 매핑

| 추출 열 | 원본 컬럼명 | 설명 |
|---------|-----------|------|
| **파일명** | `文件命名Filename` | 납품 파일명 |
| **캐릭터명** | `合并角色名` (KR) | 합산 캐릭터명. `说话人`(CN) 옆 KR 열 |
| **감정** | `注释` | 비고/감정 메모 |
| **대사** | `KR Text` | KR 대사 |
| **ALT** | 없음 | |
| **옵티컬** | `台词\nText` | CN 원문 대사 |
| **타임코드** | `时间戳\nTimeCode` | ADR용. `00:00:05.700 --> 00:00:08.140` 형식 |
| **ADR/Wild** | `是否有时间限制\nTime Limit?` | `ADR` 또는 `Wild` |
| **녹음여부** | `是否收录Record? Yes/No` | `Yes`인 행만 처리 |

---

## 4. 핵심 필터링 규칙

### 녹음 여부 필터
`是否收录` 열이 `Yes`인 행만 합본에 포함. `No`인 행은 스킵.

### ADR / Wild 구분
`是否有时间限制` 열 값으로 구분:
- `ADR`: 타임코드 있음, 영상에 맞춰 녹음
- `Wild`: 타임코드 없거나 무관, 자유 녹음

합본에서 ADR/Wild 구분을 별도 열로 표기 권장.

---

## 5. 타임코드 처리

`时间戳` 열의 타임코드를 합본에 포함한다.
형식: `00:00:05.700 --> 00:00:08.140`

타임코드에서 허용 시간 계산:
- 종료시각 - 시작시각 = 허용 녹음 시간
- ⏱ 검수 적용 가능 (template_spec.md 참조)

## 6. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | `文件命名Filename` 값 |
| 캐릭터명 | KR 캐릭터명 (`合并角色名` KR) |
| 감정 | `注释` 값 |

| ⏱ 검수 | 타임코드 기반 검수 적용 |
| [기타 원본 열] | 숨김 처리 |

> 이 타입은 표준 열 구조에 `ADR/Wild`와 `타임코드` 열이 추가됨.

---

## 7. 예외 케이스

- 타임코드 없는 Wild 행 → 타임코드 빈칸, ⏱ 검수 제외
- `交付文件夹名字`(납품 폴더명) 열 → 파일명 열 앞에 참고 열로 포함 권장
- `DialogID` 열 → 숨김 처리
