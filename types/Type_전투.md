# Type_전투 — 처리 매뉴얼

전투/보스 대화 대본. 파트마다 제목 행이 끼어 있으며, 보스 전투와 일반 전투 시트를 합본에서 1탭으로 합산한다.

---

## 1. 헤더 행 찾기

1행이 헤더가 아닌 경우가 많다:

- **boss대화**: 1행 빈 행 → 2행이 헤더
- **일반전투**: 1행 빈 행 → 2행 파트 제목 행 → 3행 빈 행 → 4행이 헤더

헤더 판단 기준: `配音对象`, `流程节点`, `对话文本`, `语音命名` 등 대본 컬럼명이 처음 등장하는 행.

---

## 2. 열 인식 및 매핑

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | `语音命名` 열. 행마다 고유한 값 |
| **캐릭터명** | `配音对象`(CN) + 옆 KR 열 쌍. KR 캐릭터명 사용 |
| **감정** | `配音备注`(CN) + 옆 KR 열 쌍. KR 감정 사용 |
| **대사** | `对话文本`(CN) + 옆 KR 열 쌍. KR 대사 사용 |
| **ALT** | `alt` 열 (있는 경우) |
| **옵티컬** | CN 원문 대사 열 (`对话文本`) |

### 일반전투 — 流程节点 KR 열 존재
일반전투 시트에는 `流程节点`(CN 전투 트리거) + KR 열 쌍이 있음.
이 열은 파라미터 열이 아닌 전투 흐름 설명 열 → 숨김 처리.

---

## 3. 파트 제목 행 vs 대사 행 구별

파트 제목 행 판단 기준 (해당 시 스킵):
- `流程节点` 열에 `第X回合`, `战斗开始`, `战斗结束` 등 전투 단계 표기가 있고
- `配音对象`(캐릭터명) 열이 비어있고
- `对话文本`(대사) 열이 비어있는 행

단, `流程节点`에 전투 단계가 적혀있어도 캐릭터명과 대사가 있으면 **대사 행**으로 처리.

### 일반전투 파트 제목 행 패턴
일반전투는 파트 제목이 더 복잡하게 끼어있음:
- 1열에 `01节`, `02节` 등 섹션 번호 + 줄거리 설명이 있는 행 → 스킵
- 헤더가 파트마다 반복 등장할 수 있음 → 헤더 반복 행도 스킵

---

## 4. 두 시트 합산 규칙

보스대화(`boss对话`)와 일반전투(`普通战斗对话`) 두 시트를 합본에서 **1탭**으로 합산.

합산 순서: **boss대화 먼저, 일반전투 뒤에**

합산 시 구분선 삽입 (선택):
- boss대화 끝 / 일반전투 시작 경계에 빈 행 1개 삽입 권장

---

## 5. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | `语音命名` 값 |
| 캐릭터명 | KR 캐릭터명 |
| 감정 | KR 감정/어투 메모 |
| REC | 비워두기 |
| 대사 | KR 대사 |
| ALT | alt 열 값 (없으면 빈칸) |
| 옵티컬(원문) | CN 원문 대사 |
| ⏱ 검수 | 비워두기 (duration 없는 타입) |
| [기타 원본 열] | 숨김 처리 |

---

## 6. 특수 처리 규칙

### 无需配音(더빙 불필요) 행
`配音备注` 열에 `无需配音` 표기된 행은 실제 녹음 대상이 아님.
→ 해당 행 스킵 또는 REC 열에 `제외` 표기 후 포함. (프로젝트 담당자 확인 후 결정)

### 备注 열에 언어 표기 (`西语` 등)
특정 대사가 스페인어/프랑스어 등으로 녹음되어야 함을 표기한 열.
→ 숨김 처리하지 않고 감정 열 옆에 참고 정보로 포함 권장.

---

## 7. 예외 케이스

- ALT 열 없는 경우 → ALT 열 생략
- 감정 KR 열 없는 경우 → CN 감정 그대로 사용
- 파일명 없는 행 → 파일명 빈칸 처리
