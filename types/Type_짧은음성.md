# Type_짧은음성 — 처리 매뉴얼

캐릭터명이 병합셀로 묶여 여러 행을 아우르는 구조의 짧은 대사 대본.
대사가 1~3어절로 매우 짧고, 한 캐릭터의 여러 라인이 병합셀 하나로 묶여 있다.

---

## 1. 헤더 행 찾기

대부분 1행이 헤더. `编号`, `角色`, `台词`, `语音备注`, `语音命名` 등 컬럼명 확인.

---

## 2. 병합셀 캐릭터명 처리 (핵심)

이 타입의 가장 중요한 처리 규칙.

**원본 구조:**
```
행2: [캐릭터CN | 캐릭터KR | 대사CN | 대사KR | 감정CN | 감정KR | ... | 파일명]
행3: [병합셀  | 병합셀   | 대사CN | 대사KR | 감정CN | 감정KR | ... | 파일명]
행4: [병합셀  | 병합셀   | 대사CN | 대사KR | 감정CN | 감정KR | ... | 파일명]
...
행N: [새캐릭터CN | 새캐릭터KR | ...]
```

**처리 방법:**
1. openpyxl로 파일 읽을 때 병합셀 정보 확인 (`ws.merged_cells`)
2. 병합셀 범위의 첫 번째 셀 값을 해당 범위의 모든 행에 복사
3. KR 캐릭터명 열의 병합셀 값을 각 행에 채워넣음

**주의:** `read_only=True`로 열면 병합셀 정보가 손실됨. 반드시 일반 모드로 열어야 함.

```python
# 병합셀 처리 예시
wb = load_workbook(filepath, data_only=True)  # read_only=False
ws = wb[sheet_name]

# 병합 범위 파악
merged = {}
for merge in ws.merged_cells.ranges:
    val_cn = ws.cell(merge.min_row, merge.min_col).value
    val_kr = ws.cell(merge.min_row, merge.min_col + 1).value
    for row in range(merge.min_row, merge.max_row + 1):
        merged[row] = (val_cn, val_kr)
```

---

## 3. 열 인식 및 매핑

| 추출 열 | 원본에서 찾는 방법 |
|---------|-----------------|
| **파일명** | `语音命名` 열. 행마다 고유한 값 |
| **캐릭터명** | `角色` KR 열. 병합셀 풀어서 각 행에 채움 |
| **감정** | `语音备注`(CN) + 옆 KR 열 쌍 |
| **대사** | `台词`(CN) + 옆 KR 열 쌍. KR 대사 사용 |
| **ALT** | 없는 경우가 대부분 |
| **옵티컬** | `台词` CN 열 |

---

## 4. 스킵할 행

- KR 대사가 비어있는 행 (CN만 있는 경우 포함)
- 병합셀 아래 완전히 빈 행

---

## 5. 추출 결과물

| 열 | 내용 |
|----|------|
| 파일명 | `语音命名` 값 |
| 캐릭터명 | 병합셀에서 풀어낸 KR 캐릭터명 |
| 감정 | KR 감정/어투 메모 |
| REC | 비워두기 |
| 대사 | KR 대사 |
| ALT | 없으면 빈칸 |
| 옵티컬(원문) | CN 원문 대사 |
| ⏱ 검수 | 비워두기 |
| [기타 원본 열] | 숨김 처리 |

---

## 6. 특수 처리 규칙

### 其他备注 열
`其他备注`(기타 비고) 열에 `拆分标记`(분리 표시), `选自正文原句`(원문 인용), `通用短语音`(공용 짧은 음성) 등 표기가 있는 경우.
→ 숨김 처리하지 않고 감정 열 뒤 참고 열로 포함 권장.

### KR 대사 없이 CN만 있는 행
번역 누락 가능성. 대사 열 비워두고 감정 열에 `[KR 번역 없음]` 표기 후 포함.

---

## 7. 예외 케이스

- 감정 CN만 있고 KR 없는 경우 → CN 감정 그대로 사용
- 파일명 없는 행 → 파일명 빈칸
- 병합셀이 아닌 일반 셀로 캐릭터명이 반복 입력된 경우 → 그대로 사용
